<h2><a href="https://www.geeksforgeeks.org/problems/perfect-cubes-in-a-range3933/1?page=4">Perfect Cubes in a Range</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given two given numbers <strong>a</strong> and <strong>b</strong> where 1 ≤ <strong>a</strong> ≤ <strong>b</strong>, find the perfect cubes between a and b (a and b inclusive). The function returns <strong>-1</strong> if there is no proper cube between the given values.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> a = 1, b = 100
<strong>Output:</strong> [1, 8, 27, 64]
<strong>Explanation:</strong> These are the proper cubes between 1 and 100.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> a = 24, b = 576
<strong>Output:</strong> [27, 64, 125, 216, 343, 512]
<strong>Explanation:</strong> These are the proper cubes between 24 and 576.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ a ≤ b ≤ 10<sup>4</sup></span>&nbsp;</p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematical</code>&nbsp;
